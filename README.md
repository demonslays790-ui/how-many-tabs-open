One number: how many browser tabs are open right now. My honest count is **137** — research tabs, docs, dashboards and a reading queue open across projects, the kind of lived-in total a heavy tab user actually ends up with. `main.py` (Python 3, standard library only) writes the number to `$MAKEFUN_OUTPUT_DIR/entry.txt` (3 characters, digits only, no trailing newline).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
